Signature part will appear here (base64url). This tool does not verify the signature — it only displays it.

A JWT signature proves the token was signed by the issuer. To verify, you need the secret or public key — this decoder intentionally skips verification and never sends your token anywhere.

How it works

Decode: Splits on . → base64url-decodes header (part 0) and payload (part 1) → JSON.parse → pretty-printed with 2-space indent.

  • exp / iat / nbf are Unix seconds; shown as UTC + local time and relative distance.
  • Signature (part 2) is displayed raw — no crypto check. Presence is optional for decoding.
  • Invalid base64url or JSON shows an error; whitespace around the token is trimmed.
  • All processing is local — paste sensitive tokens safely, but remember they may still be logged in browser history if you share a URL (this tool does not put the token in the URL).
