How it works

SHA-1 / SHA-256 / SHA-384 / SHA-512 use the browser's SubtleCrypto.digest() (Web Crypto API).

MD5 is computed with an inline JavaScript implementation (no network, no dependencies).

  • Text is hashed as UTF-8 bytes.
  • Files are read as raw bytes via ArrayBuffer.
  • Live hashing — result updates as you type or change algorithm.
  • File input takes precedence when a file is selected.
  • No data is sent to any server — everything runs locally.

MD5 is cryptographically broken — use SHA-256 or stronger for security.
