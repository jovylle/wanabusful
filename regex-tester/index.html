How to use

Type a pattern above — the tester compiles new RegExp(pattern, flags) live. Invalid patterns show an error.

  • Flags: g all matches, i case-insensitive, m ^$ per line, s dot matches newline, u unicode, y sticky.
  • Highlight: matched substrings wrapped in marks.
  • Groups table: index, full match, each capture group, and named groups.
  • Replace: preview of str.replace(regex, replacement).

Cheat sheet

  • . any char, \d digit, \w word, \s space
  • ^ $ anchors, \b word boundary
  • * + ? {n,m} quantifiers, .*? lazy
  • (…) group, (?:…) non-capturing, (?<name>…) named
  • [abc] [^abc] [a-z] character class
  • a|b alternation, \1 backreference
  • (?=…) lookahead, (?!…) negative, (?<=…) lookbehind

Tip: hover the flags to see their effect. Disable g to test single-match behavior.
