How it works

Generate renders your text to a <canvas> using the QR code library. Higher error-correction (H) helps the code stay readable if partially obscured, at the cost of density.

  • Size controls the PNG pixel dimensions (128–512).
  • Download PNG saves the exact canvas pixels — print-ready.
  • Uses qrcode via CDN when online, with an inline fallback so it works offline.

Tip: test the downloaded image with your phone camera before printing.
